## 1. Positioning Using LEO Satellite Communication Signals Under Orbital Errors

- **Title**: Positioning Using LEO Satellite Communication Signals Under Orbital Errors
  (후보 목록 원제: *Orbital Errors in LEO Satellite Positioning: Modeling, Analysis, and Bayesian Calibration*)
- **Authors**: Jie Ma, Pin-Jun Zheng, Xing Liu, Yu-Chen Zhang, Ali A. Nasir, Tareq Y. Al-Naffouri
- **Venue / Source**: arXiv 프리프린트 (Electrical Engineering and Systems Science — Signal Processing)
- **Publication date**: 2025-11-08
- **DOI / Publisher URL**: DOI 없음 (프리프린트) · arXiv ID `2511.06060` · https://arxiv.org/abs/2511.06060
- **Relevance grade**: **A**
- **한국어 요약 (3~5문장)**:
  저궤도(LEO) 위성은 GNSS의 대안으로 정밀 측위에 유망하지만, 낮은 고도로 인해 궤도 섭동에 민감하여 측위 정확도가 저하된다. 본 논문은 (i) 궤도 오차가 측위 성능에 영향을 미치는 메커니즘과 (ii) LEO 궤도 오차를 완화하기 위한 근본적 보정 전략을 연구한다. 저자들은 위성 궤도를 모델링하고 실제 TLE(Two-Line Element) 이력 데이터를 분석하여 궤도 오차의 통계적 특성을 규명하고, 이를 바탕으로 오설정(misspecified) Cramér-Rao 하한을 유도하여 궤도 오차가 측위 성능에 미치는 영향을 정량화한다. 이어 학습된 궤도 오차 통계를 사전 정보로 활용하는 베이지안 궤도 보정 프레임워크를 제안한다. 광범위한 시뮬레이션을 통해 오래된(stale) 궤도 정보가 측위 성능을 심각하게 저하시키는 반면, 궤도 오차 통계를 학습·반영하면 궤도 보정과 최종 측위 정확도를 효과적으로 향상시킬 수 있음을 보인다.
- **RFSoC 기반 LEO-PNT 연구에 중요한 이유**:
  LEO 통신 신호를 신호원(SoP)으로 활용하는 측위에서 궤도(위성 위치) 불확실성은 지연/도플러 관측치를 실제 사용자 위치로 변환하는 단계의 지배적 오차원 중 하나다. 이 논문은 궤도 오차의 통계 모델링과 CRB 기반 성능 한계, 베이지안 보정을 함께 제시하므로, RFSoC 수신기로 추정한 도플러/지연 관측치를 실제 위치 해로 변환하는 파이프라인의 오차 예산(error budget)과 보정 설계에 직접적인 이론적 근거를 제공한다.
- **잠재적으로 관련 있는 논문 섹션**: Positioning Error Model (부차적으로 System Model)
- **Recommended action**: **Read now**

## 2. An Efficient LEO Global Navigation Constellation Design Based on Walker Constellation

- **Title**: An Efficient LEO Global Navigation Constellation Design Based on Walker Constellation
- **Authors**: Yanbo Wei, Huaijian Li, Xiaojing Du
- **Venue / Source**: 2020 IEEE Computing, Communications and IoT Applications (ComComAp)
- **Publication date**: 2020-12-22
- **DOI / Publisher URL**: DOI `10.1109/comcomap51192.2020.9398888` · https://ieeexplore.ieee.org/document/9398888/
- **Relevance grade**: **C**
- **한국어 요약 (3~5문장)**:
  MEO/HEO 위성 대비 LEO 위성은 저비용, 낮은 전력 손실, 짧은 전송 지연의 장점이 있어 항법 및 위성 기반 IoT 등에 활용될 수 있다. 그러나 LEO를 항법에 적용하면 위성 수가 많아 해 공간(solution space)이 커져 전역 항법 성좌 설계가 복잡해진다. 본 논문은 성좌 고도 범위, 최소 관측 앙각, 다중 커버리지, 위성 수, DOP 값 등의 제약 조건을 고려하고, SOC(street of coverage) 기법으로 Walker 성좌를 분석하여 4중 커버리지를 위한 LEO 성좌 설계 방법을 제안한다. 결과적으로 설계된 성좌는 전역 4중 커버리지를 만족하며, PDOP 가용 영역 비율이 임계값 8에서 98.9% 이상, 임계값 4에서 94% 이상을 유지하여 설계의 타당성과 효과를 검증한다.
- **RFSoC 기반 LEO-PNT 연구에 중요한 이유**:
  성좌 기하 구조와 DOP는 도플러/신호원 측위의 관측 기하와 달성 가능한 정확도의 상한을 좌우하는 배경 요소로서 간접적으로 관련된다. 다만 본 논문은 신호 처리, 도플러/지연 추정, 수신기 구현(RFSoC/FPGA)을 다루지 않고 성좌 설계·커버리지 기하에 국한되어, 사용자의 핵심 연구 방향과의 직접적 관련성은 낮다.
- **잠재적으로 관련 있는 논문 섹션**: System Model
